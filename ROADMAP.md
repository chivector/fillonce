# Roadmap

FillOnce is built in trust-sized steps. The roadmap favors reliable evidence and editable deliverables over the number of formats on a feature grid.

## v0.1 · Native forms

- [x] Inspect native AcroForm fields
- [x] Extract facts from JSON, YAML, CSV, text, Markdown, DOCX, and PDF
- [x] Conservative multilingual aliases and conflict detection
- [x] Editable PDF output
- [x] Explicit static output with signature protection
- [x] Orphaned-widget recovery and post-write verification
- [x] Portable JSON and HTML audits with file hashes
- [x] Stateless local review UI
- [x] Local PDF preview and evidence-candidate conflict resolution
- [x] Radio-button and declared-choice writing
- [x] SHA-256 binding between review plans and original forms
- [x] Opt-in, source-bound Agent matching

## v0.2 · Better review

- [ ] Field-coordinate highlighting inside the PDF preview
- [ ] Format validators and transformations proposed as separate review actions
- [ ] Per-document trust controls
- [x] Radio-button UX and richer choice-field review
- [ ] Encrypted local fact vault

## v0.3 · Flat and scanned forms

- [ ] Text-layer field discovery for flat PDFs
- [ ] Optional local OCR adapter
- [ ] Coordinate review before drawing values
- [ ] Regression rendering across common PDF viewers

## Later, with explicit boundaries

- Browser form assistance that never clicks submit
- Pluggable extractors and institution-specific alias packs
- Team-safe, end-to-end encrypted review handoffs

Signatures and automatic submission are intentionally out of scope.
